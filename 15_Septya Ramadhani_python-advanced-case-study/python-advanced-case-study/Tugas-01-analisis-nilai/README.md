# Analisis Nilai Mahasiswa

## Deskripsi
Program ini menghitung nilai akhir mahasiswa berdasarkan nilai tugas, UTS, dan UAS. Setelah itu, program menampilkan mahasiswa yang mendapat nilai akhir di atas 80, mengurutkan peringkat dari nilai tertinggi, dan menentukan mahasiswa dengan nilai terbaik.

## Konsep Python yang Digunakan
- **List Comprehension:** mengolah dan menampilkan data mahasiswa.
- **Lambda:** menentukan dasar pengurutan nilai mahasiswa.
- **Filtering:** memilih mahasiswa yang mendapat nilai akhir di atas 80.
- **Sorting:** mengurutkan mahasiswa berdasarkan nilai akhir.

## Aturan Perhitungan
- Nilai tugas memiliki bobot 30%.
- Nilai UTS memiliki bobot 30%.
- Nilai UAS memiliki bobot 40%.
- Mahasiswa berprestasi yang ditampilkan adalah mahasiswa dengan nilai akhir di atas 80.

## Cara Menjalankan
1. Buka folder `case-01-analisis-nilai` di VS Code.
2. Jalankan `python main.py` melalui terminal.
3. Hasil perhitungan nilai dan peringkat mahasiswa akan muncul di terminal.
